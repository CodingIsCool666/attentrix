# Security

## Report A Problem

Please use GitHub's private security-advisory form for vulnerabilities that
could expose participant data, bypass local-only restrictions, or alter the
frozen production model and policy.

Do not include real meeting recordings, participant names, or private reports
in an issue. Use a minimal reproduction with synthetic data whenever possible.

## Supported Version

Security fixes are currently provided for the latest SignalRoom public beta.

## Release Verification

Every release publishes SHA-256 checksums. SignalRoom 0.1 is not code-signed,
so verify the checksum before running a downloaded installer or portable
archive.
